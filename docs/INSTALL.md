# Install

Extract a build archive to a stable user-writable directory. Place the separately obtained TGSAN YouTubeWindows distribution in a sibling `YouTubeWindows/` directory, with `YouTubeWindows.exe` at its root. Run `scripts/install-dev.ps1` from the project or extracted distribution directory; the script checks OS, executable, and process architecture, copies no user data, and creates a current-user Start Menu shortcut. Pin the shortcut from the Start Screen Apps view. The first run creates the config file when Settings are saved.
